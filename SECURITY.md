# Security Policy

## Supported Versions

Please use this table to check if your version of Eternal Social Network is still supported.

| Version | Supported |
| :------ | :-------- |
| 1.x     | ✅ Yes    |
| < 1.0   | ❌ No     |

## Reporting a Vulnerability

If you believe you have found a security vulnerability in Eternal Social Network, please **do not** report it in a public issue.

Instead, please send an email to **security@eternal.dev**.

We will attempt to acknowledge your email within 48 hours and provide an update on the investigation.
