# Support

For questions, issues, or assistance related to the Social Network project:

1. **Check Documentation:** Please review the `README.md` and `CONTRIBUTING.md` first.
2. **Search Issues:** Check existing issues in the GitHub repository to see if your question has already been addressed.
3. **Team Chat:** If you are a team member, reach out in our dedicated Team Chat.
4. **New Issue:** If you've found a bug, please open a new issue using the provided templates.
5. **Security:** For security-related concerns, refer to `SECURITY.md`.
