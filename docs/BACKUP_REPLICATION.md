# Cross-Region Encrypted Backup Replication

This document explains how PostgreSQL backups generated by `scripts/backup-db.sh` are encrypted at rest with AES-256-CBC and replicated to secondary cloud storage regions for Disaster Recovery (DR).

## 1. Local Encryption Pipeline

Backups are compressed with `gzip` and encrypted on-the-fly using OpenSSL AES-256-CBC:

```bash
pg_dump ... | gzip | openssl enc -aes-256-cbc -pbkdf2 -iter 100000 ... > backup.sql.gz.enc
```

## 2. Cross-Region Storage Replication

### Setting up AWS S3 Cross-Region Bucket (Free Tier eligible)

1. Create a primary S3 bucket in your primary region (e.g. `us-east-1`): `s3://social-network-backups-primary`.
2. Create a secondary S3 bucket in a different region (e.g. `eu-central-1`): `s3://social-network-backups-dr`.
3. Enable Object Versioning and Lifecycle Rule to transition objects to `GLACIER_IR` (Glacier Instant Retrieval) after 30 days.

### Enabling Automated Replication

Set the environment variable in `docker-compose.prod.yml` or your runner:

```env
BACKUP_S3_BUCKET=s3://social-network-backups-dr
```

When `BACKUP_S3_BUCKET` is set, `scripts/backup-db.sh` automatically syncs the verified encrypted backup archives using `rclone` or `aws s3 sync`.
