## Read the token column

`Consumed` means the named component directly references generated `--eternal-*` variables. All web components also inherit the global system font/canvas setup; that inheritance does not make their local literals token consumers. `Recipe` means Tailwind utilities, literal values or feature configuration remain the source. A similar exported value is not evidence of consumption. `Candidate` is a proposed mapping for a future change, requiring actual consumer/compositing review.

The only shared token source/export catalog is [tokens.ts](../../packages/shared/ui-primitives/src/tokens.ts), exposed as `designTokens`; [generated CSS](../../apps/web/src/shared/design/tokens.css) is its web adapter. Numbers use logical units and CSS uses rem where specified. Native clients must translate browser-only OKLCH/color-mix/shadow values and verify RGBA against the actual surface. See [token maintenance](tokens.md#maintenance).

## Continuity acceptance and evidence

The existing browser suites distinguish captures/layout from behavior: [reference](../../apps/web/e2e/design/reference.spec.ts) exercises shared keyboard/focus; [screens](../../apps/web/e2e/design/screens.spec.ts) checks Feed/Profile/Chat layouts, navigation and failed GET retry with drafts; [extended screens](../../apps/web/e2e/design/extended-screens.spec.ts) covers additional routes and targeted recovery; [themes](../../apps/web/e2e/design/themes.spec.ts), [typography](../../apps/web/e2e/design/typography.spec.ts), [effects](../../apps/web/e2e/design/effects.spec.ts) and [platforms](../../apps/web/e2e/design/platforms.spec.ts) have their own limits.

[Interaction regressions](../../apps/web/e2e/design/interactions.spec.ts) cover real Feed/Profile Like, Repost and Save in both directions during a held mutation and after refetch; completed Profile → Feed browser Back; Chat successful acknowledgement, failed send/Retry, newer draft, focus and immediate Back to chats. The [scenario contract](scenarios.md#continuous-actions-in-the-real-app) records retention boundaries. Latest measured runs are recorded in the [validation log](platform-validation.md); planned or partial runs do not certify all engines or native platforms. Follow, collections and overlay flows keep their separate coverage above.

For each future port/change, record source recipe, actual tokens, state coverage, intentional platform deviations and measured result. Exercise default/selected/focused/pressed/disabled/pending, loading/empty/failure/retry, long multilingual text, 200% text, narrow/wide windows, keyboard/safe areas, media failure and reduced effects. Navigating Feed → Profile → Chat and returning should preserve meaningful draft, scroll and focus context under the owning feature's policy. Authorization, mutation idempotency and cache correctness require separate checks from visual validation. Native screen readers, physical-device performance and offline assets remain platform release gates.
