# UI review — 21 жовтня 2026

Використано `21st-ui-review`. Навичка вже встановлена; повторне встановлення пакета не потрібне. `.21st/design.json` відсутній, тому джерелом дизайн-контексту стали [foundations](foundations.md), [design decisions](design-decisions.md), [screens](screens.md), чинні компоненти та спільні токени.

## Межі перевірки

- Початковий `21st review`: 1 633 файли вебклієнта, 130 файлів mobile, 6 файлів `packages/ui`. Це статична перевірка, включно з тестами та stories, а не доказ доступності кожного runtime-стану.
- Окремий ручний перегляд composition та AST-прохід охопив 88 production TSX-файлів shared UI / widgets; додатково перевірено знайдені проблемні місця pages/features/entities.
- Chromium + axe-core 4.13.0: 37 різних публічних сторінок при 320 × 900 та 1280 × 900, dark theme, reduced motion. Аліаси однієї сторінки не рахувалися окремо; OAuth redirects не запускалися. Зовнішні HTTP-запити блокувалися, тому перевірка не підтверджує відтворення зовнішніх медіа чи доступність сторонніх сервісів.
- Автентифіковані екрани перевірялися наявними Playwright fixtures, без production-акаунтів. Native/mobile — лише статично: viewport браузера не замінює React Native, VoiceOver/TalkBack або фізичний пристрій.
- Робоча копія вже містила зміни auth, posts, reels, search, notifications, chat та інших модулів. Вони збережені; результат оцінює поточну сукупну копію, а не чистий HEAD.

## Дизайнерські та продуктові рішення для власника проєкту

1. **Токени.** 21st позначає тисячі буквальних кольорів як можливий drift. DD-003/004/005 прямо допускають поступову міграцію, окремі brand/content palettes та feature actions. Масова заміна на один purple або один primary button не обґрунтована.
2. **Рух.** `transition-all`, hover scale і довгі durations — кандидати на спрощення. Глобальний CSS уже обробляє OS reduced motion, але це не доводить покриття всіх JS/Framer/Canvas анімацій. Потрібно визначити бажану політику для декоративних public illustrations, credits auto-scroll та media effects.
3. **Promotional UI.** Company/download/wellbeing ілюстрації показують демонстраційні чати та користувачів. Визначити, де їх варто явно назвати preview, а де зробити неінтерактивними декоративними зображеннями.
4. **Заявки на вакансії.** [JobDetailsModal](../../apps/web/src/pages/Company/ui/JobDetailsModal.tsx):27–34 показує success після таймера, без відправлення заявки. Потрібен продуктовий вибір: реальний endpoint, контактне посилання або явний demo-state. Backend інтеграцію в UI-аудиті не вигадано.
5. **Overlay contract.** Узгодити, які player/search/detail surfaces мають бути модальними. Поточні shared Modal/DropdownMenu вже задають основу, але одночасні portaled overlays потребують окремих acceptance journeys.
