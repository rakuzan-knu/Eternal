# Перевірені обмеження публікації

Стан перевірки: 5 листопада 2026. Це журнал технічних фактів і відсутніх даних,
а не юридичний висновок чи підтвердження відповідності всім законам світу.

## Оператори й контакти

За повідомленням авторів Eternal розробляють дві фізичні особи з України;
зареєстровану компанію або ФОП не надано. Імена авторів у розповіді про створення
проєкту залишено за їхнім бажанням. Авторство не замінює ідентифікацію контролера
даних або сторони договору.

Особисті email прибрано з контактних інструкцій. Власного домену та підтвердженої
публічної контактної скриньки немає. Автори попросили прямо вказувати, що контакт
не надано. Призначення DPO, реєстрацію агента DMCA, юридичний відділ і поштову
адресу не підтверджено. Відповідні позитивні твердження не слід публікувати.

Відсутність цих даних є прогалиною, а не способом уникнути обов’язків. Зокрема,
[статті 13–14 GDPR вимагають ідентифікацію та контакти контролера](https://www.dataprotection.ie/en/individuals/know-your-rights/right-be-informed-transparency-article-13-14-gdpr),
коли ці норми застосовуються. Не подавати поточні політики як завершений комплект
юридичних документів і не завершувати глобальну публікацію магазинів до усунення
прогалин та перевірки застосовності вимог.

## Інші виявлені питання

| Питання | Перевірений стан | Що залишається |
| --- | --- | --- |
| Вік | `birthDate` у контракті реєстрації необов’язковий; сервер не забезпечує заявлений регіональний віковий поріг | Визначити ринки, правові підстави й дієві правила допуску; погодити всі клієнти із сервером |
| Контент для дорослих | Правила згадують обмежені спільноти, але підтверджених age-restricted admission controls не знайдено | Узгодити правила, фактичну модерацію, вікові обмеження та анкету IARC |
| Експорт даних | `RequestDataPackageModal` показує успіх без запиту до API | Реалізувати доставку експорту або прибрати недоступну дію й непідтверджені обіцянки |
| Видалення й резервні копії | У політиках різні строки; `UsersRepository.delete` видаляє активні дані транзакцією | Перевірити фактичні backup-процедури й строки, узгодити відновлення та повідомлення |
| Інтеграції | Spotify scopes включають керування бібліотекою та відтворенням; SoundCloud використовує також guest client ID | Виправити твердження «лише читання», перевірити дозволи й умови провайдерів |
| Телеметрія | Web Sentry ініціалізується за наявності DSN | Перевірити правову підставу, інформування та фактичну дію налаштувань |
| Платні послуги | Продажі в поточній реалізації вимкнені | Прибрати позитивні обіцянки доступних підписок та непідтверджені платіжні процедури |
| Ліцензії | SBOM та каталог залежностей самі по собі не доводять виконання ліцензійних умов | Перевірити notices у фактичних web/mobile/desktop дистрибутивах та права на store metadata |

Перелік не є вичерпним аудитом усіх країн і штатів. Правила GDPR щодо дитячої
згоди залежать, зокрема, від правової підстави та країни; вони не утворюють
універсального правила «13+» для будь-якої обробки. Див.
[пояснення Європейської комісії](https://commission.europa.eu/law/law-topic/data-protection/information-business-and-organisations/legal-grounds-processing-data/are-there-any-specific-safeguards-data-about-children_en)
та [Закон України «Про захист персональних даних»](https://zakon.rada.gov.ua/go/2297-17).

## Магазини та історія Git

Microsoft Store і Snap мають зареєстровані продукти, але пакетів на публікацію
ще не подано. Точні Microsoft identity/publisher/display name є обов’язковими
для MSIX і залишаються видимими в пакеті. Вилучення їх із коду не анонімізує
Store account. Не підміняти їх вигаданою назвою юридичної особи.

Переписування Git-історії дозволено авторами. Воно потребує окремої резервної
копії, перевірки refs і узгодження локальних клонів. Воно не видаляє чужі клони,
завантажені артефакти, кеші або GitHub PR refs. Див.
[обмеження очищення GitHub](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository).
Не описувати очищення гілок як гарантоване видалення даних з Інтернету.
