Стан перевірки: 6 листопада 2026. Це журнал технічних фактів і відсутніх даних,
а не юридичний висновок чи підтвердження відповідності всім законам світу.

особи, які ведуть діяльність з України. Компанію або ФОП не підтверджено.
Публічний контакт проєкту **eternalnet.support@proton.me** створено користувачем

Mykola — основний координатор звернень, Michal — можлива підміна. Власники наразі

сповіщення працюють, доступ мають обоє та принципи розподілу погоджено обома.
Графік ще не визначено; дотримання застосовних строків не підтверджене.

Докладний [реєстр перевірок і регіональних умов](../legal/COMPLIANCE_REGISTER.md)

## Магазини та історія Git

Microsoft Store і Snap мають зареєстровані продукти, але пакетів на публікацію
ще не подано. Точні Microsoft identity/publisher/display name є обов’язковими
для MSIX і залишаються видимими в пакеті. Вилучення їх із коду не анонімізує
Store account. Не підміняти їх вигаданою назвою юридичної особи.

Перевірені 7 листопада 2026 [правила Flathub](https://docs.flathub.org/docs/for-app-authors/requirements#generative-ai-policy)
забороняють AI-generated та AI-assisted маніфести, а також автоматизацію
submission PR агентами. Для цього магазину автор має самостійно написати
маніфест і виконати подання. Попередній генератор вилучається в PR145.
Права на metadata/artwork і відповідний контрольованому репозиторію app ID
також потребують завершення.

Переписування Git-історії дозволено авторами. Воно потребує окремої резервної
копії, перевірки refs і узгодження локальних клонів. Воно не видаляє чужі клони,
завантажені артефакти, кеші або GitHub PR refs. Див.
[обмеження очищення GitHub](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository).
Не описувати очищення гілок як гарантоване видалення даних з Інтернету.
